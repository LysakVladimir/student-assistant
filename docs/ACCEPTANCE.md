# Чек-лист приёмки MVP

- [ ] `/start` создаёт профиль по Telegram ID.
- [ ] Пользователь может добавить занятие, увидеть его в расписании и удалить.
- [ ] Занятия разных пользователей изолированы.
- [ ] Физкультура автоматически добавляет форму и обувь.
- [ ] Лабораторная автоматически добавляет методичку и тетрадь.
- [ ] Окна длиной от 40 минут отображаются.
- [ ] Время выхода учитывает путь, сборы и запас.
- [ ] При отсутствии занятий бот сообщает об этом.
- [ ] Mini App требует валидный Telegram initData вне dev-режима.
- [ ] При отключённом LLM сохраняется базовая функциональность.
- [ ] API-документация открывается по `/docs`.
