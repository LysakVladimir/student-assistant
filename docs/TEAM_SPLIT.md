# Распределение задач команды

1. **Backend Lead** — модели и миграции, авторизация Mini App, API, Docker, тесты.
2. **Bot Developer** — команды, клавиатуры, уведомления и сценарии диалога.
3. **Agent Developer** — tool-calling, промпты, fallback, набор тестовых сценариев.
4. **Integration Developer** — погода, геокодирование, маршруты, транспорт, кэш.
5. **Frontend Developer** — Mini App, UX, валидация форм, адаптивность.

Для команды из 3 человек:
- участник 1: backend + БД + деплой;
- участник 2: бот + расписание;
- участник 3: Mini App + агент/интеграции.
