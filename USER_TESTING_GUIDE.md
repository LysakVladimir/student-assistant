# Самостоятельная проверка StudyPilot на Windows 11

Инструкция рассчитана на первый запуск. Команды вводятся в PowerShell; строки с секретами никому не отправляйте.

## A. Подготовка компьютера

1. Установите Docker Desktop с официального сайта Docker и перезагрузите Windows, если установщик попросит.
2. Откройте Docker Desktop. Дождитесь надписи **Engine running**.
3. Откройте PowerShell: меню «Пуск» → введите `PowerShell` → Enter.
4. Выполните `docker version`. Успех: показаны секции Client и Server. Ошибка «docker не найден» означает, что Docker Desktop не установлен или терминал был открыт до установки; перезапустите Docker Desktop и PowerShell.
5. Перейдите в проект:
   ```powershell
   cd C:\Projects\student-assistant
   ```
6. Проверьте наличие `.env`: `Test-Path .env`. Ожидается `True`. Если `False`, выполните `Copy-Item .env.example .env`.
7. Откройте `.env` в Блокноте: `notepad .env`. Не добавляйте кавычки вокруг обычных значений.

При Docker отдельная установка Python/Node.js/MySQL не нужна. Для запуска без Docker нужны Python 3.12 и Node.js 20+, но для первого теста рекомендуется Docker.

## B. Настройка Telegram

1. В Telegram откройте официальный `@BotFather`, отправьте `/newbot`, задайте имя и username, оканчивающийся на `bot`.
2. Скопируйте токен и вставьте в `.env` после `TELEGRAM_BOT_TOKEN=`. Не публикуйте его.
3. В BotFather отправьте `/setprivacy`, выберите бота, затем **Disable**. Иначе бот будет видеть только команды, упоминания и replies, но не обычную переписку.
4. Создайте отдельную тестовую группу. Добавьте бота через «Участники» → «Добавить».
5. В «Управление группой» → «Администраторы» добавьте бота. Для теста достаточно возможности читать сообщения и отправлять ответы; удаление сообщений не требуется.
6. В группе администратор отправляет `/ai_on`. Успех: бот сообщает, что анализ включён и участники уведомлены.
7. Каждый пользователь, которому нужен доступ в личном AI-чате, отправляет в группе `/ai_join`.
8. Интерактивное участие необязательно: `/ai_interactive on`. По умолчанию бот молчит и только анализирует. Выключение: `/ai_interactive off`; полный stop новых данных: `/ai_off`.

## C. Настройка AI

### Подключение Polza.ai

1. Откройте [polza.ai](https://polza.ai), зарегистрируйтесь и создайте отдельный API-ключ только для StudyPilot. Ключ обычно начинается с `pza_`.
2. В кабинете Polza задайте денежный лимит ключа. Для первого ручного теста используйте минимальный приемлемый лимит; приложение не обходит внешний лимит.
3. Разрешите только необходимые модели: `deepseek/deepseek-v4-flash`, `deepseek/deepseek-v4-pro` и `baai/bge-m3`. Не добавляйте дорогие модели без необходимости.
4. Откройте `.env`: `notepad C:\Projects\student-assistant\.env`.
5. Добавьте конфигурацию без кавычек:
   ```env
   AI_PROVIDER=polza
   POLZA_API_KEY=pza_ваш_секретный_ключ
   POLZA_BASE_URL=https://polza.ai/api/v1
   AI_PRIMARY_MODEL=deepseek/deepseek-v4-pro
   AI_BACKGROUND_MODEL=deepseek/deepseek-v4-flash
   AI_EMBEDDING_MODEL=baai/bge-m3
   AI_DEFAULT_MODE=auto
   AI_MONTHLY_COST_LIMIT_RUB=500
   AI_ADMIN_TELEGRAM_ID=ваш_telegram_id
   ```
6. Сгенерируйте две разные длинные случайные строки и задайте `APP_SECRET` и `INTERNAL_API_TOKEN`.
7. Перезапустите: `docker compose up --build -d backend bot`.
8. Откройте Mini App → AI. Ожидается: провайдер `polza`, статус «подключён», основная модель Pro, фоновая Flash.
9. В Telegram выполните `/ai_mode`. Переключение: `/ai_mode economy`, `/ai_mode auto`, `/ai_mode quality`. Настройка хранится в MySQL и переживает перезапуск.
10. Задайте простой вопрос в economy и сложный вопрос в auto. В ответе Mini App отображается фактически использованная модель. Техническая статистика доступна через `GET /api/agent/usage` в Swagger.
11. Следите за стоимостью одновременно в Mini App/API StudyPilot и кабинете Polza. Значения могут различаться из-за округления, кешированных/reasoning-токенов и тарифных правил шлюза; внешний кабинет является источником списания.
12. Чтобы проверить 402 безопасно, уменьшите внешний лимит ключа или используйте отдельный тестовый ключ с исчерпанным лимитом. Ожидается: платные вызовы прекращаются без бесконечных retry, новые сообщения остаются в очереди, администратор получает предупреждение.
13. После пополнения/изменения лимита подождите час либо администратором вызовите `POST /api/agent/ai-settings/reset-provider` в Swagger, затем повторите один запрос.
14. Замена модели выполняется в `.env` через `AI_PRIMARY_MODEL`/`AI_BACKGROUND_MODEL`, затем `docker compose up -d --force-recreate backend bot`.
15. Временно отключить весь AI: `AI_ENABLED=false`; только фон: `AI_BACKGROUND_ENABLED=false`; для отдельного пользователя — переключатель Mini App; для отдельного чата — «Передавать сообщения внешнему AI».

Контролируемая проверка Polza без вывода ключа (каждая команда выполняет один платный короткий запрос):

```powershell
cd C:\Projects\student-assistant
$keyLine = Get-Content .env | Where-Object { $_ -like 'POLZA_API_KEY=*' } | Select-Object -First 1
$polzaKey = $keyLine.Split('=', 2)[1].Trim()
$headers = @{ Authorization = "Bearer $polzaKey"; 'Content-Type' = 'application/json' }
$body = @{ model='deepseek/deepseek-v4-flash'; messages=@(@{role='user';content='Ответь одним словом: готов'}); max_tokens=10 } | ConvertTo-Json -Depth 5
$result = Invoke-RestMethod -Method Post -Uri 'https://polza.ai/api/v1/chat/completions' -Headers $headers -Body $body
$result | Select-Object model, usage, cost
Remove-Variable polzaKey
```

Ожидается модель Flash, короткий ответ и `usage`. Для одного Pro-теста замените только model на `deepseek/deepseek-v4-pro`; не запускайте команду циклом. Затем сравните usage/cost с `GET /api/agent/usage` и кабинетом Polza. Прямой PowerShell-запрос не попадёт во внутренний журнал StudyPilot — для проверки журнала задайте вопрос через Mini App.

DeepSeek V4 Pro является текстовой моделью. Flash принимает изображения, но не аудио. Для транскрибации голосовых сохранена необязательная интеграция Gemini: добавьте `GEMINI_API_KEY` и `GEMINI_MODEL`. Не запускайте платные мультимодальные испытания без предварительной оценки тарифа.

Для OpenAI/OpenRouter/Anthropic задайте `AI_PROVIDER`, `AI_API_KEY`, модели и при необходимости `AI_BASE_URL`. Для локального OpenAI-compatible сервера используйте `AI_PROVIDER=local`.

Без API key доступны регистрация групп, приём/очередь сообщений, эвристические задачи, локальный поиск, ссылки и расписание. Необработанные записи не теряются и будут обработаны после восстановления AI.

## D. Запуск

1. Убедитесь, что Docker Desktop запущен и PowerShell открыт в `C:\Projects\student-assistant`.
2. Выполните:
   ```powershell
   docker compose up --build -d
   ```
3. Проверьте контейнеры: `docker compose ps`. У `mysql`, `backend`, `bot`, `frontend` ожидается `Up`; backend и MySQL должны стать healthy.
4. Откройте http://localhost:8000/health. Ожидается `{"status":"ok"}`.
5. Откройте http://localhost:8000/docs — это API-документация.
6. Откройте http://localhost:5173 — локальный Mini App. В обычном браузере он работает только при `VITE_DEV_AUTH=true`; не включайте этот режим на публичном сервере.
7. В личном чате Telegram отправьте `/start`, затем `/today`, `/weather`, `/ai`.
8. Логи: `docker compose logs -f backend bot`. Выход из просмотра — `Ctrl+C`; контейнеры продолжат работать.
9. Корректная остановка без удаления данных: `docker compose stop`.
10. Повторный запуск: `docker compose start`. Пересборка после изменения `.env`: `docker compose up --build -d`.
11. Не выполняйте `docker compose down -v`: ключ `-v` удалит volume MySQL.

Если Mini App нужен внутри Telegram, нужен HTTPS URL. Разместите frontend/backend на HTTPS, задайте `WEBAPP_URL` и `VITE_API_URL`, затем настройте Menu Button в BotFather.

## E. Обязательная проверка исправленного маршрута

Перед тестами выполните `docker compose up --build -d` и откройте два окна логов:

```powershell
docker compose logs -f bot
docker compose logs -f backend
```

В кабинете Polza для каждого AI-запроса проверяйте модель, статус и отсутствие `toolChoice: required` у обычного диалога. Не запускайте сценарий циклом.

| Тест | Куда и что отправить | Ожидается | Как проверить | При ошибке |
|---|---|---|---|---|
| 1. Рекурсия | Личный чат: `Что такое рекурсия?` | Содержательный ответ, без расписания | Ответ относится к рекурсии; в Polza один text chat | `docker compose logs --tail 100 bot backend` |
| 2. Контекст | Сразу там же: `Объясни еще проще` | Упрощение предыдущего ответа | Ответ явно продолжает тему рекурсии | backend log и `/api/agent/usage` |
| 3. Сложный вопрос | `/ai_mode quality`, затем в личном чате: `Сравни символный искусственный интеллект и машинное обучение с примерами гибридного подхода` | Сравнение по существу, без плана | В usage фактическая Pro; в Polza нет tools | backend log, Polza generation log |
| 4. Упоминание | В группе после `/ai_interactive on`: `@имя_бота Что такое рекурсия?` | Один reply от бота | Сообщение также появилось в сохранённой истории | bot + backend logs |
| 5. Актуальное собрание | Сначала отправить два сообщения из теста 6; затем в Mini App выбрать группу и спросить `Когда и где состоится собрание?` | Четверг, 16:00, аудитория 410 | В ответе есть source-ссылка на изменение | backend log; AI → поиск/факты |
| 6. История изменения | В группе: `Собрание состоится в среду в 12:00 в аудитории 201`, затем `Внимание, собрание переносится на четверг, 16:00, аудитория 410`; спросить `Как менялись договоренности по собранию?` | Исходно среда 12:00/201, затем четверг 16:00/410 | Оба исходных сообщения показаны источниками | backend log; `analysis_queue`, `memory_facts` через UI/API |
| 7. Задачи | В группе: `Иван должен подготовить презентацию до пятницы`, `Мария должна отправить отчет до четверга`, `Алексей отвечает за бронирование аудитории`; затем `/tasks` в личном чате | Три поручения; сроки у Ивана/Марии | Сверить AI → «Задачи и решения» и ссылки | backend batch log, `/api/agent/facts` |
| 8. Лабораторная | В группе: `Для лабораторной работы № 5 необходимо использовать PostgreSQL`, затем `Работу нужно сдать до 28 ноября`; спросить в Mini App `Что нужно для лабораторной № 5 и когда сдавать?` | PostgreSQL, срок 28 ноября | Оба сообщения в sources | backend log, поиск Mini App |
| 9. Неизвестный факт | В Mini App: `Какой номер телефона у преподавателя?` | Прямо сказано, что номера в доступной истории нет; номер не выдуман | Sources пусты или не содержат телефон | backend log и выбранный chat filter |
| 10. Перезапуск | `docker compose restart`, дождаться healthy, повторить тесты 5 и 7 | История, задачи и доступ сохранились | `docker compose ps`; ответы совпадают по фактам | `docker compose logs --tail 200 mysql backend bot` |

Дополнительно повторите проблемный пример: в группе напишите `ГУАП сгорел, поэтому во вторник отменяют пары`. В фактах он должен иметь `uncertain` и confidence не выше 50%, а ответ обязан говорить, что это утверждение из переписки без установленной достоверности.

## F. Расширенный ручной сценарий

В тестовой группе последовательно отправьте (можно копировать):

1. `Экзамен по физике предварительно планируют на 18 декабря, но преподаватель ещё не подтвердил.` Ожидается: предположение не становится подтверждённым фактом.
2. `Решили: консультация будет 16 декабря в 15:00 в аудитории 401.` Ожидается: решение/событие появляется в «AI → Задачи и решения».
3. `Иван, подготовь презентацию и пришли до пятницы.` Ожидается: задача с исполнителем/сроком, если модель уверенно их извлекла.
4. Ответьте reply на сообщение 2: `Перенесли на 17 декабря, 16:00.` Ожидается: сохраняется связь reply и фиксируется изменение.
5. Отредактируйте сообщение 3. Ожидается: в БД остаётся одна версия сообщения с обновлённым текстом, факты пересчитываются.
6. Отправьте голосовое: `Встречаемся завтра после второй пары.` При отдельно настроенном Gemini ожидается транскрипция; одна Polza/DeepSeek-конфигурация аудио не поддерживает, поэтому сохраняются метаданные и очередь не должна падать.
7. Отправьте фото с текстом. DeepSeek Flash должен извлечь содержание после пакетной обработки. PDF напрямую DeepSeek не считается гарантированно поддерживаемым; неподдерживаемый файл не должен остановить бота.
8. В личном чате спросите: `Что обсуждали сегодня?`, `Что решили по консультации?`, `Какие задачи поручили Ивану?`, `Какие вопросы остались нерешёнными?` Ожидается ответ только по доступным чатам и ссылки на сообщения supergroup, когда Telegram допускает ссылку.
9. Уточните: `А когда именно?` Ожидается использование недавнего контекста диалога; при недостатке данных агент прямо об этом сообщает.
10. В Mini App → AI выберите конкретный чат и режим «Кратко/Подробно», повторите вопрос.
11. Создайте монитор `перенос экзамена`, затем напишите в группе `Экзамен перенесли на 20 декабря.` Ожидается одно личное уведомление; повтор в течение cooldown не дублируется.
12. В Mini App включите ежедневную сводку. Она отправляется в выбранный час (по умолчанию 20:00) при плановом проходе на 5-й минуте часа.
13. Выполните `docker compose restart`. После запуска повторите вопрос: прежняя история должна сохраниться.
14. Другим Telegram-аккаунтом, не выполнявшим `/ai_join`, попробуйте спросить о группе. Ожидается отсутствие доступа и отсутствие утечки.
15. Выполните `/ai_off`, отправьте новое тестовое сообщение и убедитесь, что оно не появилось в поиске.
16. Администратор может нажать «Удалить историю» в Mini App. Это необратимо для сохранённой истории этой группы; Docker volume при этом не удаляется.
17. Проверьте маршрутизацию: в economy простой и сложный вопрос должны показать Flash; в auto подробный вопрос по нескольким чатам — Pro; фоновый пакет при любом режиме — Flash. Сверьте поле `model` в ответе и `/api/agent/usage`.
18. Отправьте 5–20 коротких сообщений подряд. В статистике ожидается один пакетный `background_analysis`, а не отдельный платный вызов на каждое сообщение.

Импорт старой истории: экспортируйте чат в Telegram Desktop как JSON и отправьте объект с полем `messages` через Swagger, маршрут `POST /api/agent/chats/{chat_id}/import`. Делайте импорт блоками до 10 000 сообщений. Бот не может получить старую историю самостоятельно.

## G. Неполадки

- **Бот не отвечает:** `docker compose ps`, затем `docker compose logs --tail 100 bot`. Ошибка 401 обычно означает неверный/отозванный токен. Исправьте `.env` и выполните `docker compose up -d --force-recreate bot`.
- **Бот не видит обычные сообщения:** отключите Privacy Mode, удалите и заново добавьте бота в группу, затем `/ai_on`. Проверьте права.
- **AI не отвечает:** проверьте имя переменной ключа, модель, квоту и `docker compose logs --tail 100 backend`. Расписание и fallback должны продолжить работать.
- **Polza возвращает 402:** пополните баланс/увеличьте внешний лимит, не добавляйте обходной ключ. Сообщения остаются в очереди. После восстановления сбросьте provider breaker через администраторский endpoint или дождитесь автоматической контрольной попытки.
- **Polza возвращает 401:** вставьте ключ повторно без кавычек и пробелов, пересоздайте backend. `GET /models` может работать без ключа и не подтверждает его валидность; проверяйте коротким chat-запросом.
- **Очередь растёт:** откройте Mini App → AI, проверьте статус провайдера и `pending_messages`; затем `docker compose logs --tail 200 backend bot`. Не удаляйте записи вручную.
- **История не сохраняется:** проверьте `/ai_on`, `INTERNAL_API_TOKEN`, health backend и логи обоих сервисов. Токен должен быть одинаковым, поскольку используется один `.env`.
- **Нет уведомлений:** проверьте правило в Mini App, cooldown, `/ai_join` и что совпавшее сообщение новое. Мониторинг сравнивает смысловые ключевые слова и не гарантирует совпадение слишком общих формулировок без AI.
- **База не запускается:** `docker compose logs mysql`; проверьте свободен ли порт 3307. Не удаляйте volume. После исправления выполните `docker compose restart mysql backend bot`.
- **Контейнер не стартует:** `docker compose config` найдёт ошибки YAML/env; затем `docker compose up --build` без `-d`, чтобы видеть ошибку.
- **Mini App не открывается в Telegram:** Telegram требует HTTPS и URL, заданный в BotFather. `localhost` подходит только обычному браузеру на компьютере.
- **Кнопка Mini App отсутствует:** задайте реальный HTTPS `WEBAPP_URL` без `example`/`localhost` и пересоздайте bot-контейнер.
- **Неверный ответ:** откройте источники. Если исходных данных недостаточно, добавьте уточнение; не считайте AI-ответ заменой официального объявления.
