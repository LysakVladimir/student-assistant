# student-assistant
# Универсальный интеллектуальный ассистент студента

**Интеграция академического расписания, логистики и контекстных рекомендаций.**

## 📌 О проекте

Приложение-помощник, которое автоматизирует рутину учебного дня. Система динамически анализирует расписание, строит маршрут до вуза с учётом времени выхода и пробок, а также формирует список вещей, которые нужно взять с собой, исходя из специфики конкретных пар.

## ⚙️ Функционал

- **Умный будильник** — «Выходи через 15 минут, иначе опоздаешь на пару».
- **Контекстный рюкзак** — если в расписании «Физкультура» — напомнить про форму; если лабы — про методичку.
- **Анализ окон** — предложить, где можно пообедать или позаниматься в свободное окно между парами.
- **Синхронизация с погодой** — «На улице дождь, а ты пешком — возьми зонт и выйди на 10 минут раньше».
